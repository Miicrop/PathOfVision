## 0.1.0

First release.

- Reads Eldritch Altar options from the screen and recommends one according to a profile.
- HUD that highlights the recommended option and dims the others.
- Settings and profiles window, tray icon, optional autostart.
- Resolution scaling by client height. Verified on real screenshots at 1080, 1200, 1353 and 1440 px (1920x1080, 1920x1200, 2560x1353, 3440x1440), 16:10 and wider; heights up to 2160 px (4K) and aspects narrower than 16:10 or wider than about 2.6:1 run with an "untested resolution" note.
- Per-user Windows installer; the app checks GitHub Releases for updates at start and installs them while Path of Exile is closed.
